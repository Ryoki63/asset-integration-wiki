# 道具の提供方法を選ぶ

箱札を作りたい人が必要としているのは、毎回使える道具でしょうか、それとも当日貼る札でしょうか。必要な結果が同じでも、端末に何を置けるか、入力をどこで扱えるかによって提供方法が変わります。以下は架空例の選択肢で、採用実績ではありません。

**道具を渡す。** 受付の端末で何度でも作り直せます。入力を外部に出せない場合にも使いやすい一方、実行許可、配布する権利、更新版を誰が入れるかを先に確認します。

**サービスとして使ってもらう。** 利用者は画面から入力し、提供側の環境で札を作ります。処理を利用者端末に配らずに済む一方、入力の送信可否、保存期間、利用者の認証、運営担当が論点になります。画面だけ用意しても、ネットワークが使えない会場には向きません。

**結果だけ渡す。** 開催が一度なら、提供側で処理し印刷用の札を渡す方法があります。導入は軽くなりますが、直前に冊数が変わると利用者が自分で訂正できません。再発行の担当と所要時間を決めておきます。

**次の実験案：** 受付終了後に数量が一度変わる条件で、誰がどのデータを持ち、正しい札を再発行できるかを3方式で比較する。方式を決める前に、入力を動かせる範囲と利用者自身が行いたい作業を確認します。
