# アセット統合活動 Wiki

このWikiでいう「アセット」は、別の仕事でも使い直せる道具や手順のことです。二つの道具をつないだとき、片方の出力をもう片方が正しく使えるか。作った人がそばにいなくても、同じ結果を出せるか。公開できる小さな実験を通じて、その確かめ方を記録します。

## ここから読む

- **[接続を試す：図書交換会の箱札](handoff.html)** — 蔵書リストを箱札に変換します。「読み込めた」と「正しい札を作れた」の違いを、単位の取り違えから確かめます。
- **[提供方法を選ぶ](delivery.html)** — 同じ箱札の道具を、配布する・ブラウザで使う・結果だけ渡す場合に分けて考えます。
- **[活動記録と次の実験](journal.html)** — 何を試し、どこまで確認できたか。追加検証はここから追えます。

記録の対象は繰り返し使える仕組みです。個別案件の納品や受入を、アセットの再利用実績には数えません。
