# 活動記録と次の実験

## 2026-11-27｜箱札の受け渡し実験

- **問い：** 入力がJSONとして読めても、受け手が意味を間違える入力を見分けられるか。
- **確認済み：** [掲載例](handoff.html)で「8冊」は `こもれび：8冊` と出力。「8箱」と書式の版 `2` は拒否。元の入力に戻すと同じ札を出力できた。
- **未確認：** 別の担当者が手順だけで再実行できるか。実際のプリンターで正しく印刷できるか。入力した冊数が現物と一致するか。
- **次の実験案：** 訂正前の札が残るケースを扱い、古い札をどの時点で無効にするかを決める。[提供方法別の違い](delivery.html)も比較する。

次の記録では、実行日、使った入力の版、観察した結果、前回から変わった点を追記します。
