# アセット統合活動 Wiki

[公開Wikiを読む](https://ryoki63.github.io/asset-integration-wiki/) · [初回の公開実験](docs/handoff.md) · [活動記録](docs/journal.md)

公開可能な実験を、入力・期待結果・確認できた範囲とともに記録するためのリポジトリ。公開サンプルはこのWiki用に作成した架空データです。

## 更新方法

活動の状態は `docs/_data/activity.yml` に記録します。日付・結果・次の確認・根拠記事を1か所で更新すると、Pagesのビルド時にトップと「活動の現在地」の両方に反映されます。

1. `docs/` の該当記事を編集し、活動記録 `journal.md` に日付・変更点・根拠・未確認事項を追記します。新しいページには `layout: wiki` と `title:` を付け、目次と `.gitignore` の許可リストに追加します。
2. 差分と記事のリンクを確認し、公開できる変更だけを `main` に反映します。公開リポジトリではPR・履歴・添付も公開されます。非公開の下書きはリポジトリ外で扱ってください。
3. GitHub Pages が `main` の `/docs` を自動ビルドします。Actionsの「pages build and deployment」で結果を確認できます。

次段階の自動化案は、公開に使える入力だけを別途指定し、変更を検出したら記事案と前回との差分を作ること。入力元の自動収集はまだ有効にしていません。
